# Origin · 一条链（17.5 s）

用 [onetake](https://github.com/feitangyuan/onetake) 做的第二支 Origin 片子。第一支是 38 秒的星空图谱（`docs/video/origin-promo.mp4`），暗底、发光节点；这一支故意反过来：暖光桌面、白纸、一条红笔迹。

## 概念

> 全片只有一个主角：一条先修链。它先是一张卡片上的一根红线，然后从桌面上立起来，变成空间里 11 层物理的链，镜头骑在链上往回飞，停在根因；链压平、变成 AI 讲解面板；最后链被抽出来，写成字标。

选它的理由：Origin 干的事就是「沿先修关系往回追，找到真正没学会的那一步」，而这正好是一条线能画出来的动作。参考片（B 站那条 Blender 展示片）的语言是「深色空间里设备漂浮、镜头在屏间飞」——我借了它的镜头语法（长而软的 travel + 真实运动模糊），但换了底色，因为上一支片子已经是深色的。

被否掉的两个方案：

- **下潜**（`dusk` 暗紫，镜头从卡片穿进去 11 次，每次更短更快）——视觉冲击最强，但底色与上一支片子太近，会读成同一支片的第二版。
- **成绩单裂开**（`ultramarine` 饱和蓝，错答裂成三个错因再往下裂成树，硬切簇）——节奏最硬，但整片蓝底 17 秒会压得慌，而且「树」和「链」讲的是同一件事，没必要。

## 数据是真的

链上 11 个节点不是画的：`promo/build_graph.py` 在真实的 `public/data/dependencies.json` 上跑 BFS 求出这条路径，再写进 `comp.html` 的 `NAMES` / `GRADES` 常量（这两个数组要和数据一致，改了数据就得重跑）：

```
配方法(九) → 完全平方公式(八) → 多项式乘多项式(八) → 单项式乘多项式(八) → 合并同类项(七)
→ 乘法运算律与多个因数相乘(七) → 有理数的乘法法则(七) → 绝对值的化简与计算(七)
→ 相反数(七) → 在数轴上表示有理数(七) → 有理数的分类(七)  ← 根因
```

年级是从九年级一路退到七年级的，这件事本身就成立了「一路退回去」的叙事，不需要额外解释。每张牌子上的「N 年级」也是 `topics.json` 里的真实字段。

界面卡片是 `origin.new.tg` 的 2× 截图（3840×2160），用 Playwright 在真实站点上抓的。

## 数值

- 17.5 s / 1920×1080 / 30 fps / 180° 快门（真实运动模糊，按 `__motion` 自适应采样）
- 探针：soft 曲线占 74%，中位 t80 **0.77**（参考片 90% / 0.83）；峰值 397 px/帧在 10.10 s 的收束段
- 音频：峰值 −3.6 dBFS，RMS −19.5 dB

## 被否掉的做法

- **诊断卡片**：本来要三张屏。诊断结果页必须真的把 40 道题做一遍才能拿到，Playwright 驱动了两轮（第一次 6 分 48 秒还没跑到结果，第二次章节选择器没点开），拿到的都是空起始页。三张屏里有一张纯白空页比两张屏更糟，砍成两张。
- **第一版配色**：直接量产品色（`look.py from-shot`）得到 `#f5f3ef` 底 + `#fff` 卡片，白上加白，全片糊成一片。桌面压到 `#efeae0` 并加暗角、卡片加浏览器窗栏和描边，才读得出「屏幕」。
- **年级刻度栏**：左侧竖排「九/八/七」本来想强化退级感，实际和根因牌子撞在一起，删掉——牌子上的「N 年级」已经够了。
- **颗粒/发光**：上一支片子用发光节点，这一支一律不用。红笔迹只有 3.2 px，底下垫一条 11 px、13% 透明度的同色，是为了在亮底上压住重量，不是发光。
